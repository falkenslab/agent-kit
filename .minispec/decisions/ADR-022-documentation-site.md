# ADR-022: A versioned documentation site on GitHub Pages

## Decision

The developer documentation is a Docusaurus site in `docs/`, its own npm project, published to GitHub Pages (`https://falkenslab.github.io/agent-kit/`) by a GitHub Actions workflow on every push to `main`. Hand-written guides live in `docs/content/`; the API reference is generated by TypeDoc (`docusaurus-plugin-typedoc`) from `src/index.ts`'s exports on every build. Each release snapshots the documentation as a version (`npm run docs:version -- X.Y.Z`); the latest release is the default at `/docs`, `main` is "Next (unreleased)" at `/docs/next`.

## Motivation

- Developers building agents learned the kit from the README, Captain Whiskers' code and doc comments readable only in an editor; `.minispec/` explains the kit to whoever works on it, not how to build with it.
- A generated reference can't drift from the code, and it makes every undocumented export visible.
- Versions matter because the kit is `0.x`: a minor release may change behavior, and someone pinned to an older version must find the documentation of that version.
- Docusaurus handles versions, search, and broken-link checks out of the box; GitHub Pages keeps the site next to the code, with no other service.

## Consequences

- Documentation is part of every change: a change visible to agents updates `docs/content/` in the same change, and a release checks the guides are up to date before snapshotting them (`release`, `verify`, `add-export` and `minispec-implement` skills say so).
- `verify` builds the site, which fails on a broken link or anchor.
- `docs/` is outside the npm package (`files` lists `dist/` and `assets/`) and outside the root lint; its dependencies are its own.
- Guides are CommonMark (`.md`, `markdown.format: "detect"`), not MDX: doc comments and guides are full of `<placeholders>` MDX would read as tags.
- `docs/assets/` stays shared with the README (the Captain Whiskers screenshot) and is served as a static folder.
- Every public export needs a doc comment; one without shows as "-" in the reference.
