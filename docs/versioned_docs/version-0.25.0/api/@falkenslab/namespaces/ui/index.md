# ui

The terminal palette: one function per theme role, drawing text in the current theme.

## Functions

| Function | Description |
| ------ | ------ |
| [accent](functions/accent.md) | The accent (the approval panels' border). |
| [action](functions/action.md) | The plain console's `[action]` lines (`action` role). |
| [agent](functions/agent.md) | The agent's label and texts (`agent` role). |
| [bold](functions/bold.md) | Bold, whatever the theme. |
| [code](functions/code.md) | Inline code and code blocks. |
| [dim](functions/dim.md) | Secondary text (`dim` role). |
| [error](functions/error.md) | Errors (`error` role). |
| [heading](functions/heading.md) | Titles (`heading` role, bold by default). |
| [italic](functions/italic.md) | Italics, whatever the theme. |
| [strike](functions/strike.md) | Strikethrough, whatever the theme. |
| [success](functions/success.md) | Good outcomes (`success` role). |
| [toolBullet](functions/toolBullet.md) | The `●` before a tool call (`toolBullet` role). |
| [toolLabel](functions/toolLabel.md) | A tool call's label. |
| [toolResult](functions/toolResult.md) | The one-line result under a tool call. |
| [user](functions/user.md) | The person's prompt label (`user` role). |
| [userBar](functions/userBar.md) | The background of the human's lines. |
| [warn](functions/warn.md) | Warnings and notices (`warn` role). |
| [working](functions/working.md) | The spinner and what the agent is doing. |
